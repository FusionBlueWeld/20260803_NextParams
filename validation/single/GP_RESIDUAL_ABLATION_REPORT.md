# v003 GP残差アブレーション検証レポート

実施日: 2026-09-09

## 結論

今回の条件では、GP残差の平均補正は残す価値があります。ただし、確認できた効果は
「最適解へ大幅に早く到達する」ことではなく、予測空間全体の誤差と尤度を小さく改善することです。

- 最適格子点の到達率は両方式とも `8/9`（88.9%）で同じでした。
- 到達ステップの paired 比較は GP残差ありが `2勝 / 7分 / 0敗` でした。
- 全体 macro NRMSE は GPあり `0.043470`、なし `0.043715` で、GPありが
  `0.000245`（出力幅の0.0245%相当、相対0.56%）良好でした。
- 全体 macro NRMSE の paired 勝敗は GPありが `8勝 / 0分 / 1敗` でした。
- 局所 macro NRMSE は GPあり `0.010831`、なし `0.010870` で、差はさらに小さく、
  paired 勝敗も `6勝 / 0分 / 3敗` でした。
- Gaussian NLPD は全体で GPあり `3.1445`、なし `3.2285`、局所で
  GPあり `-2.7899`、なし `-2.7848` でした（低いほど良好）。
- 95%区間被覆率は全体で約73.1%、局所で約92.2%でした。残差平均の有無による差は
  ほぼありません。特に全体の73%は名目95%より低く、現在の不確かさは過小評価です。

したがって、GP残差は「小さいが再現傾向のある平均補正」と評価します。現時点では削除する
根拠はありませんが、探索速度を主要な採用理由にはできません。また、尤度校正を改善するには
GP残差平均ではなく、NN不確かさ・モデル不一致・supportと分散の接続方法を別途見直す必要があります。

## 検証設計

v003の製品コードを変更せず、`train_hybrid_model`と`run_optimization`を検証コードから
直接呼びました。比較した平均は次の2条件です。

```text
GPあり: hybrid_mean = nn_pred + support * gp_residual_mean
GPなし: hybrid_mean = nn_pred
```

GPなしでも、獲得関数に使う`gp_std`と`support`は同じ学習済みモデルから残しました。
これにより、GP残差の平均補正だけを切り分けています。これは「GP部品を完全に除去する比較」
ではありません。

- 物理シミュレータ: `thermal_curing`、`press_forming`、`convection_drying`
- seed: `0, 1, 2`
- seedの役割: 初期実験条件の選択。NN初期化seedは製品版と同じ`42`固定
- 初期実験: 各27点
- 追加実験予算: 最大15点、1反復1推薦
- 測定値: 決定論的な物理シミュレータ真値（追加ノイズなし）
- 知識損失: 両条件とも objective の `lower_bound=0`、strength 2を1件
- 最適解: 各problem.csvで定義された候補格子上の制約付き真の最適点
- checkpoint: 最適点を測定データへ追加した直後。未到達時は15反復終了時
- 局所window: 真の最適点から正規化入力距離`<=0.20`

各物理シミュレータの全格子真値は採点にだけ使用し、モデル学習や推薦には渡していません。

## 指標別の結果

### 1. 最適解への到達ステップ

未到達は`>15`です。

|工程|seed|GPあり|GPなし|判定|
|---|---:|---:|---:|---|
|熱硬化|0|12|12|同じ|
|熱硬化|1|13|13|同じ|
|熱硬化|2|4|5|GPありが1反復早い|
|プレス成形|0|>15|>15|両方未到達|
|プレス成形|1|2|2|同じ|
|プレス成形|2|2|3|GPありが1反復早い|
|熱風乾燥|0|3|3|同じ|
|熱風乾燥|1|2|2|同じ|
|熱風乾燥|2|2|2|同じ|

GP残差による悪化は見られませんでしたが、7/9は同着です。探索速度の効果は限定的です。

### 2. 最適解到達時の予測空間精度

NRMSEは各出力のRMSEを、その出力の全格子上の値幅で割り、出力間で単純平均しました。

|範囲|GPあり|GPなし|GP - なし|paired勝敗（GP/同点/なし）|
|---|---:|---:|---:|---:|
|全格子 macro NRMSE|0.043470|0.043715|-0.000245|8 / 0 / 1|
|局所 macro NRMSE|0.010831|0.010870|-0.000038|6 / 0 / 3|

工程別では、全体NRMSEは3工程とも平均でGPありが良好でした。局所NRMSEは熱硬化と
熱風乾燥でGPありが良好、プレス成形では平均差`+0.000075`でわずかに悪化しました。

### 3. 尤度と局所window

尤度は出力幅で正規化したGaussian NLPD、区間校正は95%予測区間の真値被覆率です。

|指標|GPあり|GPなし|評価|
|---|---:|---:|---|
|全体 macro NLPD|3.1445|3.2285|GPありが良好|
|局所 macro NLPD|-2.7899|-2.7848|GPありがわずかに良好|
|全体 95% coverage|73.14%|73.15%|実質同じ、両方とも過小被覆|
|局所 95% coverage|92.23%|92.10%|実質同じ、名目95%に近い|

平均補正は尤度を少し改善しましたが、分散自体は比較条件間で同じ定義なので、coverageの
差がほぼないことは自然です。全体の過小被覆は、現行`hybrid_std`が残差GP由来のみで、
NNの不確かさやモデル形式誤差を含まないことと整合します。

### 4. seed再現性

全体NRMSEは9組中8組、局所NRMSEと局所NLPDは9組中6組でGPありが良好でした。
一方、到達ステップの改善は9組中2組だけで、残り7組は同じです。工程別にも、熱風乾燥では
差がほぼ消え、プレス成形seed 0では両方式とも未到達でした。

よって「GP残差が常に大きく効く」とは再現していません。「全体精度を小さく改善する傾向」は
seedをまたいで比較的一貫し、「到達速度を改善する効果」は弱く工程依存、という結論です。

同一seedの決定性も、熱硬化seed 0を1反復だけ別出力へ再実行して確認しました。GPあり・なし
とも推薦点と推薦スコアが本実行の1反復目と完全一致しました。

## 考察と制約

1. 3工程はいずれも滑らかで決定論的であり、27点の初期設計とNNだけでも全体傾向をかなり
   学習できます。残差GPが補正すべき成分が小さく、効果量も小さくなりました。
2. v003はGP残差平均へsupportを掛けるため、補正は実測支持がある領域に限られます。
   これは外挿暴走を抑える一方、未観測域の探索順位を大きく変えにくい設計です。
3. 両条件でGP標準偏差を残したため、Expected Improvementの探索圧は共通です。到達速度が
   ほぼ同じなのは、平均補正より共有した不確かさが探索を支配した可能性があります。
4. 到達時checkpointは各arm固有です。2組ではGPありが1反復早いため、GPあり側は1点少ない
   データで採点されています。それでも平均差はGPあり優位でしたが、純粋な同一データ精度比較
   ではありません。
5. seedは初期設計だけを変え、NN seedは固定です。3 seedは傾向確認には使えますが、統計的な
   一般化には少数です。測定ノイズ、誤った知識、強い知識、5〜10 seed、高次元工程は未検証です。
