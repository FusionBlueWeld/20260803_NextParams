# 塗膜の熱風乾燥

## 目的

これは、平板ウェブ上の水系塗膜を熱風で乾燥する問題を表す、決定論的な
物理構造付き合成モデルである。絶対値は生産設備に合わせて校正しておらず、
ParamOptimizer の制約付き探索を検証するために使用する。

固定条件は、平板金属ウェブ上の代表的な水系ポリマー塗膜、乾燥固形分面密度
`0.050 kg/m²`、塗膜厚さ `0.35 mm`、初期水分率 `28 wt%`（湿量基準）、相対湿度
`35%`、入口温度 `25 °C` とする。材料、ウェブ幅、ノズル形状、風向、膜厚、
初期水分、湿度、塗膜の熱物性、乾燥機の熱効率・ファン効率、検査方法、摩耗状態は
固定し、出力ごとの乱数やファイル入出力は持たない。

## 入力・出力と制約

入力は熱風温度 `air_temperature_c`（45--105 °C、5 °C刻み）、熱風速度
`air_speed_m_s`（0.5--6.0 m/s、0.5 m/s刻み）、滞留時間 `residence_time_min`
（1--12 min、1 min刻み）である。全組合せは `13 × 12 × 12 = 1,872` 点である。

目的は面積当たりエネルギー `energy_kj_m2`（kJ/m²）の最小化。制約は
`residual_moisture_pct <= 7`（残留水分率、湿量基準の%）と
`defect_index <= 0.28`（無次元、0--1）である。残留水分率は常に
`100 m_water / (m_dry + m_water)` で計算し、乾燥によって負値にならない。

## モデル式

空気側の対流熱伝達係数は、速度の飽和効果を含む次式（W/(m² K)）で置く。

```text
h = 12 + 42 (1 - exp(-v / 1.25))
T_surface = 25 + (T_air - 25) [1 - exp(-h t / C_A)]
```

ここで `v` は m/s、`t` は s、`C_A = 0.37 × 1700 = 629 J/(m² K)` は
熱風でのウォームアップを表す、塗膜＋ウェブ基材をまとめた有効面積熱容量である。
`0.37 kg/m²` は初期湿塗膜の質量そのものではなく、この一次遅れ近似のための固定した
熱容量質量である。塗膜内の有効水分拡散係数（m²/s）は温度依存の合成式

```text
D_eff = 7.0e-12 exp[0.042 (T_mean - 25)]
k_int = π² D_eff / (4 L²)       [1/s]
```

とする。外部抵抗は、代表長さ `L_c = 0.012 m` を使った

```text
Re = ρ_air v L_c / μ
Sh = 2 + 0.90 Re^0.5 Sc^(1/3)
k_m = Sh D_v / L_c               [m/s]
J_ext = 0.12 k_m Δρ_v             [kg/(m² s)]
k_ext = J_ext / m_water,0         [1/s]
```

で表す。`Δρ_v = 0.65 p_sat(T_mean) M_w / [R(T_mean+273.15)]` は固定相対湿度を
使った蒸気密度差である。`0.12` は塗膜表面交換の経験係数であり、外部境膜と
塗膜表面の実装状態を表す合成部分である。直列抵抗は

```text
1 / k_overall = 1 / k_int + 1 / k_ext
m_water(t) = m_water,0 exp(-k_overall t)
```

とし、初期水分量は湿量基準から `m_water,0 = 0.050 × 0.28/(1-0.28)
= 0.01944 kg/m²` と換算する。

乾燥欠陥は測定確率ではなく、速く乾く表面層と直列抵抗で乾くバルクの差を使う
合成指数である。温度と風速から攻撃度 `a` を作り、
`k_surface = k_int (1 + 2.25 a)`、`f_surface = 1-exp(-k_surface t)` として、
`defect_index = clip(1.35 max(f_surface-f_bulk,0) + thermal_shock + short_time,
0,1)` とする。高温・高速・短時間ほど表面/core差が強くなり、長時間では差が
緩和される。このため、残留水分制約だけでなく欠陥制約も探索面の一部で有効になる。

エネルギーは全て面積基準にそろえ、各項を J/m² で計算した後に 1,000 で割り、
次式の kJ/m² とする。

```text
E_kJ/m² = [m_wet cp (T_air - 25) / η_heat
         + (m_water,0 - m_water) λ / η_evap
         + 0.085 v³ t] / 1000
```

角括弧内の各項は順に顕熱、蒸発潜熱、ファン仕事で、単位は J/m² である。
ここでエネルギー収支の `m_wet = 0.06944 kg/m²` は初期湿塗膜の質量であり、
ウォームアップ式の有効熱容量質量 `0.37 kg/m²` とは異なる。`cp = 1700 J/(kg K)`、
`λ = 2.35e6 J/kg`、`η_heat = 0.76`、`η_evap = 0.80` を固定し、計算結果は
kJ/m²に変換する。ウォームアップはこの有効熱容量による一次遅れの近似であり、
蒸発潜熱による温度低下との完全な連成は解いていない。全項が非負なので出力エネルギーも
正である。

## 物理構造と合成部分

温度による加熱、一次遅れ型の温度追従、拡散時間スケール、Reynolds--Schmidt--
Sherwood 型の外部移動、蒸気圧駆動力、直列抵抗、顕熱・潜熱・ファン仕事の単位は
物理的な骨格である。一方、固定交換係数、拡散係数の温度係数、欠陥の重み、
効率、相対湿度、代表長さは検証用に選んだ経験的・合成的な値であり、実機の
材料同定や品質保証に流用しない。有限な入力に対して同じ配列を返し、スカラー、
ベクトル、異なる形状の多次元配列も `np.broadcast_arrays` で評価する。
