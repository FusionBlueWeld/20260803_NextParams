# v002 → v003 総合進化比較レポート

## 結論

v003 は、特に高次元・複雑系における**平均予測面と制約判定、最適解への到達性**では v002 より明確に進化している。一方、現状の GP 残差が出す分散は過小で、**尤度・95%区間の校正と一部 seed の探索安定性は v002 より悪い**。したがって、v003 の構成（NNを基準面、GPを残差補正に使う）は残すべきだが、現状の不確実性をそのまま信頼して完成版と判断すべきではない。

実運用上の判断は「v002へ戻す」ではなく、**v003を採用候補とし、残差GP分散へNNの外挿不確実性または校正係数を加えて再評価する**のが妥当である。

## 比較条件

- v002: 直接GPとNNのsupport blend、知識損失なし
- v003: NN基準面 + GP残差、目的値 `lower_bound=0`, `strength=2` の最小知識あり
- 物理シミュレータ: 低次元3系（thermal curing、press forming、convection drying）と8入力の複雑系2系（electroplating、milling）
- seed: 0, 1, 2
- 同一seedでは初期実験点、候補格子、観測ノイズ0、推薦数1、最大15ステップを共通化
- 到達判定: 制約を満たし、大域最適目的値を持つ任意の格子点。同率最適も含む
- 予測評価: 到達時点（未到達は15ステップ後）の全候補、局所半径0.20、最適近傍nearest-64

これは製品版 v002 と v003 の総合比較であり、GP残差だけの因果効果ではない。GP残差単独の効果は別のON/OFF ablationで評価する。

## 主要結果

| 対象 | 指標 | v002 | v003 | 解釈 |
|---|---:|---:|---:|---|
| 全15試行 | 最適到達率 | 53.3% | 73.3% | v003が改善 |
| 全15試行 | censored到達中央値 | 15 | 3 | v003が大幅に短縮 |
| 全15試行 | 到達 W/T/L | 2 / 5 / 8 | 8 / 5 / 2 | v003優勢 |
| 全15試行 | 全体 NRMSE | 0.0855 | 0.0464 | v003が45.7%低い |
| 全15試行 | feasible accuracy | 0.9377 | 0.9730 | v003が改善 |
| 全15試行 | nearest-64 NRMSE | 0.0491 | 0.0345 | v003が29.8%低い |
| 全15試行 | Gaussian NLPD | -1.200 | 6.347 | v003が大幅に悪化 |
| 全15試行 | 95% coverage | 98.9% | 66.6% | v003は過信 |
| 全15試行 | 最終regret平均 | 0.00211 | 0.00311 | v003がやや悪化 |

到達 W/T/L は各seedのペア比較における v002勝 / 同着 / v003勝。未到達は16として比較した。

### 低次元・単純系

- 到達率は v002 66.7% → v003 88.9%、到達中央値は11 → 3。
- 全体 NRMSE は0.0486 → 0.0435で小幅改善。
- nearest-64 NRMSE は0.00894 → 0.01321で悪化し、単純系の最適近傍では v002 が優位。
- coverage は98.8% → 73.1%へ悪化。
- 最終regret平均は0.000392 → 0.001781。press forming seed 0で v003 が外した影響が大きい。

単純系では基準面をNNへ移す利点が小さく、v003の到達改善はあるものの、局所精度と不確実性の代償が目立つ。

### 高次元・複雑系

- 到達率は v002 33.3% → v003 50.0%、censored到達中央値は16 → 9.5。
- 全体 NRMSE は0.1408 → 0.0508で63.9%改善。
- nearest-64 NRMSE は0.1094 → 0.0664で39.3%改善。
- feasible accuracy は0.8793 → 0.9612へ改善。
- 一方で coverage は99.1% → 56.9%、NLPDは -0.344 → 11.150へ大幅悪化。

milling では同率最適が84点ある。これを正しく数えると、v002は2/3 seedで到達（到達ステップ16, 2, 12）、v003は3/3 seedで到達（1, 2, 3）した。平均予測面・局所面とも v003 が明確に良い。

electroplating では両版とも全seedで未到達だった。v003は全体 NRMSE と制約判定を改善したが、seed 1・2で最終regretが悪化した。平均面が良くても不確実性が過小なため、獲得関数が誤った領域を強く選ぶという失敗と整合する。

## 4指標への回答

1. **最適解への到達ステップ**: 総合ではv003が優位。15ペア中8勝、5分、2敗。複雑系では2勝4分0敗。
2. **到達時の予測空間精度**: 全体面はv003が明確に優位。特に高次元で NRMSE を約64%低減。
3. **尤度と局所精度**: 点予測の局所精度は複雑系で改善するが、NLPDとcoverageは大幅悪化。点予測精度と不確実性精度は別物であり、今回もっとも重要な未解決点。
4. **seed再現性**: millingの改善は3 seedで概ね再現したが、electroplatingとpress formingに悪化seedがある。3 seedだけで頑健性を断定はできない。

## なぜこの結果になったか

高次元格子では観測点近傍のsupportが薄い候補が大半になる。v002はその領域で直接GP側へ寄りやすく、大域的な面を表現しにくい。v003はNNを大域的な基準面とし、GPを観測済み残差の局所補正に限定するため、複雑系の全体NRMSEと制約判定が改善したと考えられる。

一方、v003の `hybrid_std` は主に残差GPの不確実性であり、NN基準面の外挿誤差を十分に含まない。そのため平均が真値に近くても区間が狭すぎ、coverage低下とNLPD悪化を招いた。探索ではこの過信が acquisition score に入り、electroplatingのような複雑な制約面でseed依存の誤探索につながった可能性が高い。

今回の知識は「目的値は0以上」という弱い下限制約だけで、多くの真値領域では自明かつ損失が発火しにくい。したがって、今回観測した高次元での改善の主因は、強い専門知識ではなく v003 のNN基準面 + GP残差という構造変更と考えるのが妥当である。

## 採用判断と次の検証

GP残差学習は**入れた方がよい**。ただし採用対象は平均補正としての残差GPであり、現状の分散推定を無修正で探索へ使うことは推奨しない。

次に優先すべき修正は以下。

1. `hybrid_std` にNN ensemble/MC dropout等の基準面不確実性を合成する。
2. validation seedで分散スケールまたはconformal intervalを校正する。
3. electroplatingを主対象に10〜30 seedへ増やし、到達率・regret分布・coverageを再評価する。
4. v003の知識あり/なしも分離し、構造変更と知識損失の寄与を切り分ける。
