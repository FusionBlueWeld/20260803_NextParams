# 樹脂・接着剤の熱硬化ベンチマーク

このフォルダは、固定した材料・工具条件の下で、樹脂または接着剤の塗布層をオーブン加熱する工程を探索するための、決定論的な合成モデルです。実機の配合同定や品質保証に使う校正済み物理モデルではありません。目的は、熱遅れ、硬化、過熱劣化、制約付きの非単調な最適化を再現可能な小さな問題として提供することです。

## 固定条件と仮定

- 材料は、同一配合・同一ロットの熱硬化性樹脂／接着剤です。密度、熱伝導率、比熱、反応次数、触媒量、ガラス転移、金属被着体、初期含水率は全試行で固定し、個別には同定しません。
- 工具は温度制御されたオーブンとし、扉開閉、風速、治具の熱容量、被着体の厚さ、放射率、周囲温度を固定します。周囲温度は 25 °C です。
- 塗布層厚さは入力ですが、材料と塗布面積は固定です。厚い層ほど熱の一次遅れ時定数が長くなるとします。
- 摩耗は、ノズル・塗布工具・治具の摩耗がない（または交換済み）固定条件です。摩耗粉、ノズル詰まり、塗布量の経時変化はモデル化しません。
- オーブン設定温度は保持中一定で、予熱中のオーブン側の変動は無視します。層内温度は一つの集中定数温度で近似します。
- 真値関数は乱数、ファイル書き込み、外部データ読み込み、隠れた状態を持ちません。同じ入力は常に同じ出力になります。

## 入力・出力と探索問題

`problem.csv` の軸は 9 × 13 × 9 = 1,053 点です。

| 変数 | 単位 | 役割 | 範囲・目標 |
| --- | --- | --- | --- |
| `oven_temperature_c` | °C | 入力 | 100–180、刻み 10 |
| `hold_time_min` | min | 入力 | 5–65、刻み 5 |
| `layer_thickness_mm` | mm | 入力 | 0.10–0.50、刻み 0.05 |
| `bond_strength_mpa` | MPa | 目的（maximize） | 大きいほど良い |
| `cure_fraction` | fraction | 制約（greater_equal） | 0.80 以上 |
| `degradation_fraction` | fraction | 制約（less_equal） | 0.20 以下 |
| `peak_temperature_c` | °C | モニター | 到達ピーク温度 |

硬化率と劣化率は 0 以上 1 以下の無次元量です。温度を上げたり保持時間を延ばしたりすると硬化は進みますが、十分高温・長時間では劣化が進みます。そのため、接着強度の最大化は単純な「高温・長時間」ではなく、硬化制約と劣化制約の間に探索すべき領域を持ちます。厚さは熱遅れを増やし、硬化不足になりやすい一方、経験的な厚さ係数にも影響します。

## 計算式

温度は絶対温度を `T` [K]、温度差を °C と同じ数値で扱い、時間 `t` [min] に対して次で計算します。

```text
tau(L) = 0.8 + 8.0 * (L / 0.50 mm)^2                 [min]
T(t) = 25 °C + (T_oven - 25 °C) * (1 - exp(-t/tau))
```

`tau` の厚さ二乗は熱拡散の代表時間を表す簡潔な集中定数近似です。硬化と劣化の速度は、基準温度で速度を定義した Arrhenius 形です。

```text
k_cure(T) = 0.018 min^-1 * exp[(65000 J/mol)/R * (1/393.15 K - 1/T)]
k_deg(T)  = 0.003 min^-1 * exp[(80000 J/mol)/R * (1/443.15 K - 1/T)]
R = 8.314462618 J/(mol K)

E_cure = integral(k_cure(T(t)) dt)
E_deg  = integral(k_deg(T(t)) dt)
alpha  = 1 - exp(-E_cure)
damage = 1 - exp(-E_deg)
```

積分は保持時間を 192 等分し、各区間の中点で評価するベクトル化された中点則です。一次反応の区間更新を指数形でまとめるため、変換率は丸めによらず `[0, 1]` に収まります。`peak_temperature_c` は保持終了温度（この単調な履歴ではピーク温度）です。

接着強度は次の合成式です。`L` は mm、`alpha` と `damage` は fraction、出力は MPa です。

```text
f_L = 0.83 + 0.17 * exp(-((L - 0.24 mm) / 0.16 mm)^2)
bond_strength_mpa = 4.0 MPa
                    + 62.0 MPa * f_L * alpha^0.72 * exp(-3.0 * damage)
```

一次遅れ、Arrhenius の温度依存、一次反応の有界変換は物理的な構造です。`f_L` の広い山形、指数係数、強度スケール、基準速度、活性化エネルギーは、この検証問題のための透明な経験的ベンチマーク係数であり、普遍定数や特定製品の校正値ではありません。劣化は競合する高温損傷の合成指標です。
