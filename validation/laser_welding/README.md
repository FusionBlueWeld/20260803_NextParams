# レーザー溶接

既存の溶接モデルを6工程共通の検証機構へ接続したものです。軟鋼相当の厚板、
連続発振ガウシアンビーム、固定焦点・表面・シールドガスを想定します。
係数は合成データ用で、実測による校正値ではありません。

## 入力と検査結果

|入力|範囲|刻み|
|---|---|---|
|laser_power_w|100–6000 W|200 W（上端を追加）|
|spot_diameter_um|50–300 µm（1/e²直径）|25 µm|
|scan_speed_mm_s|10–1000 mm/s|25 mm/s（上端を追加）|

溶込み深さ `penetration_depth_mm` を最大化し、スパッタの序数レベル
`spatter_level_0_9 <= 4` を満たす条件を探します。
関数は吸収率、規格化エンタルピー、キーホール移行度などの診断値も返します。

## 式と検証目的

ガウシアンのピーク強度 `I = 8P/(πd²)`、線エネルギー `P/v`、
規格化エンタルピー、深さの `P/(dv)` スケーリングを組み合わせます。
吸収率を反復更新し、熱伝導モードからキーホールモードへの移行を表します。
深さの上限、移行幅、スパッタの重みと0–9への量子化は仮定した補正式です。
相互作用・飽和・急な移行・離散的制約を同時に検証できます。

候補13,981点、初期27点の旧条件を維持しています。
グリッド上の制約付き最良は5900 W / 300 µm / 60 mm/s、
深さ8.386370654563162 mm、スパッタ4です。連続空間の大域最適値を意味しません。

既存コードの `evaluate_model(power_w, spot_um, speed_mm_s, params=None)` は維持。
共通APIでは `load('laser_welding').evaluate({...})` に上記CSV列名を使用します。
旧 `validation/oracle/physics_model.py` はこの実装への互換入口です。
元資料の `dataset_19()` は参考となる熱入力の例で、数式の出典は既存溶接モデルです。
