# 複合工程物理シミュレータ検証レポート

## 物理oracleの基準監査

- 基準全体空間: 9操作条件、各3水準、19,683候補
- 最終仕様適合: 1,341候補
- 最終仕様不適合: 18,342候補

各工程のscalar/配列broadcast、決定論性、入力境界、主要物理傾向、工程間の値の一致、
manifest接続、最終合否、seed固定ばらつき評価を検査しました。

## 個別Best連結と全体調整

局所目的だけで順番に選んだ条件は、塗工の固形分処理量、乾燥エネルギー、硬化後接着強度を
それぞれの局所制約内で最適化します。しかし最終膜厚が89.018 µmとなり、全体仕様上限
85 µmを超えて不合格でした。512シナリオの基準工程ばらつきに対する良品率は7.8125%です。

全体の正規化仕様余裕を最大にした粗い基準候補は、最終仕様に適合し、仕様余裕0.4464、
同じ512シナリオで良品率100%でした。この数値は指定した検証用ばらつき分布と粗い候補
空間に対するoracle基準であり、実機歩留まりを表しません。

機械可読な条件、全中間状態、ロバスト性指標、ソースハッシュは
[`results/reference_audit.json`](results/reference_audit.json) に保存しています。

合格する共通基準条件に対して、宣言範囲内の操作条件だけを変更しました。

## 現在の検証範囲と境界

v004では、塗工・乾燥・硬化を個別trialとして各15反復し、各推薦のoracle値を次の学習データへ戻す閉ループを3 seedずつ実施しました。硬化は広域128点の学習で3 seedともheld-out NRMSEが基準を超え、512点に増やした再実行で3 seedとも合格しました。統合結果は [`stage_closed_loop_final_validation.json`](results/stage_closed_loop_final_validation.json) にあります。

r001では学習済みstage bundleの接続、全体候補の選択、oracleとの照合を確認していますが、3工程を通した推薦・oracle測定・再学習の反復閉ループは未検証です。良品確率の校正、実機保証、潜在原因推定、情報価値に基づく後戻り実験も対象外です。

結果は決定論的な合成物理oracleに対するものです。実機の歩留まりや連続領域での大域最適性を示しません。初期試行・smoke・修正前ログは [`_old/validation/multistage/results/README.md`](../../_old/validation/multistage/results/README.md) に整理しています。
