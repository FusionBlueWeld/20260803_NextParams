# 機能性コーティング複合工程の物理設計

## 目的と位置付け

このモデルは、塗工、熱風乾燥、熱硬化を独立した決定論的oracleとして評価し、
同じモデルを工程間状態で接続するための検証用縮約モデルです。特定の材料・設備に
校正した実機予測器ではありません。主要な支配因子、単位、境界挙動、物理傾向を
維持しつつ、全候補評価と反復最適化が可能な計算量に抑えています。

## 塗工

ウェブ速度を `U`、粘度を `mu`、表面張力を `gamma` とし、塗工ビードの状態を
キャピラリー数で表します。

```text
Ca = mu U / gamma
wet thickness = gap × transfer ratio(Ca, viscosity, web tension)
```

ギャップが膜厚の主因です。低いCaではリビング・濡れ不足、高いCaでは空気同伴、
中央から外れた張力では幅方向膜厚変動が増える形にしています。固形分・溶剤質量は、
ポリマー密度と溶剤密度の理想体積加成から求め、乾燥工程の質量収支と整合させます。

局所目的は単位幅当たり固形分処理量の最大化です。膜厚変動係数と塗工欠陥指数を
局所制約にします。最終膜厚は局所制約に含めないため、局所Bestが全体Bestになるとは
限りません。

## 熱風乾燥

湿潤膜と支持体を集中熱容量系として扱い、膜温度を一次遅れで計算します。

```text
T(t) = T0 + (Tair - T0) × (1 - exp(-t/tau))
D(T) = D0 × exp(k × (T - T0))
k_internal = pi^2 D / (4 L^2)
1/k_overall = 1/k_internal + 1/k_external
Msolvent(t) = Msolvent(0) × exp(-k_overall t)
```

内部拡散抵抗は膜厚の二乗で増え、外部物質移動は風速に対して飽和します。表面側の
除去速度と全体速度の差をskinning indexとし、急速な表面乾燥による内部応力・欠陥へ
反映します。乾燥膜厚は固形分体積と残留溶剤体積の和です。エネルギーは顕熱、蒸発潜熱、
ファン仕事を正値で合算します。

局所目的は乾燥エネルギー最小化で、残留溶剤と乾燥欠陥を局所制約にします。

## 熱硬化

膜厚依存の熱時定数で温度履歴を作り、硬化・熱劣化・溶剤脱離をそれぞれArrhenius型
速度で96分割の中点積分を行います。

```text
k(T) = k_ref × exp[E/R × (1/T_ref - 1/T)]
conversion = 1 - exp(-integral(k(T) dt))
```

硬化が溶剤脱離より先行すると、厚膜・高温ほど蒸気が閉じ込められるblister indexが
増えます。最終接着強度は硬化率で増加し、熱劣化、残留溶剤、内部応力、継承欠陥で
連続的に低下します。ニップ圧は接触を改善しますが、過大な圧力は不均一膜に転写欠陥を
生じさせます。硬化収縮、圧密、応力を最終膜厚と寸法変化へ反映します。

局所目的は接着強度最大化です。硬化率、劣化率、残留溶剤、最終欠陥を局所制約にします。

## 工程接続と最終判定

接続は [`process_manifest.json`](functional_coating/process_manifest.json) に明記し、
`pipeline.py` が次の状態を値のコピーなしに受け渡します。

```text
塗工 → 湿潤膜厚、固形分率、膜厚CV、塗工欠陥
乾燥 → 乾燥膜厚、残留溶剤、内部応力、乾燥欠陥、膜厚CV
硬化 → 接着強度、硬化率、劣化率、残留溶剤、最終膜厚、欠陥、寸法変化
```

最終合否には、接着強度、硬化率、劣化率、残留溶剤、欠陥、寸法変化、最終膜厚を
使用します。`quality_margin` は全仕様までの正規化余裕の最小値で、正なら全仕様合格、
負なら少なくとも一つが不合格です。これは校正済み故障確率ではありません。

## 決定論と工程ばらつきの分離

3つの `physics_model.py` と `pipeline.py` は乱数を使用しません。同じ入力はbit単位で
同じNumPy出力を返します。`robustness.py` だけが、設定誤差と原料変動をseed固定の
正規分布シナリオとして作ります。物理真値と工程ばらつきを分離することで、将来の
モデル不確実性、検査ノイズ、工程ばらつきを別々に評価できます。

`stage_freeze_yield_improvement` は、同一乱数系列のまま一工程の変動だけを固定した場合の
良品率変化です。原因候補を調べる診断であり、因果寄与の総和が100%になる指標では
ありません。

## 基準空間

9つの操作条件を各3水準とした19,683候補を基準空間にします。原料状態は基準値に固定し、
個別Best連結、全体仕様余裕最大、全体適合条件内の最小エネルギー・最大処理量を比較します。
この粗い空間は最適化アルゴリズムの正解oracleであり、連続空間の厳密最適を主張しません。

## 原因工程が既知の介入

`fault_scenarios.py` は、合格する共通基準条件に対し、塗工ギャップ偏り、乾燥滞留時間不足、
硬化温度不足、3工程にまたがる小さな複合偏りを与えます。すべて宣言範囲内の入力で物理
モデルをそのまま評価し、意図した工程ラベル以外を使って出力を改変しません。将来のNG
原因推定はこのラベルを見ずに順位付けし、既知の原因工程と照合できます。

## v004・r001構想への適合評価と修正方針（2026-09-07）

**直列3工程の状態接続を検証するoracleとして使えます。** 操作条件と流入状態が分離され、
配列の同じ位置を同じ仮想製品として下流へ渡す構造は、新しいv004・r001方針に合っています。
ただし、現在は物理式を直接接続した試験装置で、学習済みbundleの互換性・確率精度・現場の
観測可能性は未検証です。以下は今後の修正方針であり、既存コードに実装済みではありません。
単工程の操作互換は[validation側の評価](../single/README.md)と分担します。

### 最適化・確率評価の不足

- `benchmark.individual_best_chain()`は上流Bestの状態を使って下流を順次最適化する比較基準。
  固定された各工程の既存Best行をそのまま連結する試験とは別に扱い、比較方式を記録する。
- 全体候補は現在、最終仕様中心で採点し、個別Bestの局所制約を再適用していない。
  必須工程制約と譲歩可能な局所目標を設定で分け、同じ必須制約の下で比較する。
- `quality_margin`は最小正規化仕様余裕であり、良品確率ではない。余裕最大化を比較基準に
  残し、確率最大化は別の選択処理・独立シナリオで評価する。
- `robustness.py`は独立した入力正規乱数を上下限でクリップする。端点に確率が集まる方式で、
  切断正規分布とは異なる。既存seed回帰用に保持し、新しい試験ではクリップの設備的意味、
  相関・共通ロット変動・範囲外の扱いを宣言した分布を別設定で用意する。
- 検査ノイズとモデル不確実性は未実装。工程変動→oracle真値→測定の層を分け、学習モデルの
  不確実性は学習側が推定する。既知の多出力・共通ロット相関を持つシナリオを使い、
  同一シナリオの維持だけで相関を再現したと判断しない。
- 良品確率は点推定だけでなくサンプル数・seed・推定区間を記録する。512件全合格でも真の
  良品確率100%とは扱わない。モデル不確実性による幅とMonte Carlo推定誤差も分ける。
- `stage_freeze_yield_improvement`は仮想的な変動固定の感度で、原因確率ではない。
  `fault_scenarios.py`は原因ラベル付き条件介入で、潜在設備ドリフト推定の実証ではない。
  後続試験では設定値と実効値を分離し、原因ラベル・隠れ状態を診断器から遮断する。

### 修正順と受け入れ条件

1. **接続形式**：oracleアダプター、必須入力・単位・意味・範囲検査を追加し、現行pipelineと
   全中間状態・最終合否を一致させる。最終膜厚の`between`もr側の両側制約として維持する。
2. **学習接続**：流入状態も変化させた実験生成・学習を追加する。固定原料の19,683候補は
   回帰基準に残し、別ロット・流入状態・境界を含む未学習点で工程別／最終誤差と支持域を評価する。
3. **確率接続**：観測契約、要因別ばらつき、同時サンプルを追加し、最終合否のBrier score、
   予測確率と実際の合格割合、予測区間被覆率を独立データで検証する。各指標の対象を記録する。
4. **全体調整**：必須制約と設備前提を揃え、個別Bestと全体調整を同じ候補・予算で比較する。
   NG原因推定・後戻り実験はこの後の別段階とする。

物理式・指標・分布・制約を変える場合はモデル／設定版とハッシュを更新し、旧基準値を保存します。
現行22テストは基礎oracleの回帰に使い、上記の未実装機能を保証するテストとは扱いません。

## モデルの位置付け

各 `physics_model.py` は、熱・物質移動、キャピラリー数、Arrhenius型反応など、対象現象の支配因子を残した決定論的な物理縮約モデルです。同じ入力には常に同じ出力を返し、実機校正済みのCAEやデジタルツインではありません。係数・適用範囲・品質式は、最適化機能と工程接続を検証するための明示的なベンチマーク仮定です。

塗工、乾燥、熱硬化はそれぞれ `evaluate_model()` で単体利用できます。全入力はNumPyのscalar／配列に対応し、共通形状へbroadcastされます。`pipeline.evaluate_line()` は塗工出力を乾燥へ、乾燥出力を硬化へ渡し、最終仕様と `quality_margin`、`feasible` を返します。

## 決定論oracleとロバスト性評価

物理モデルの出力は決定論oracleです。工程条件を変動させたロバスト性評価（Monte Carlo等）の乱数は、物理モデル本体とは分離して `robustness.py` 側で扱います。したがって、同じ中心条件の真値を再評価でき、乱数によるばらつき評価と物理式の正解値を混同しません。

工程間の主な接続状態は、湿潤膜厚、固形分率、膜厚変動、残留溶剤、内部応力、欠陥指数です。各工程の `manifest.json` は操作条件、流入状態、出力の名前・単位・適用範囲・説明を記録します。
