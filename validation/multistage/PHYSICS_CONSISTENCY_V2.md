# 塗工ラインの物理整合性 v2

2026-10-26、元コミット e7d919a04b0a794ef59f383feb83070c909aed60。
本変更は工程別改善候補の第1段階で、温度・溶剤質量・膜厚・連続搬送の整合性を扱う。
実機の精度向上を実証する校正ではなく、未校正の合成モデルの内部整合性の修正である。

## 温度と質量

- 乾燥の `terminal_film_temperature_c` を硬化の `incoming_film_temperature_c` に接続する。
  工程間の搬送冷却はゼロと仮定する。単独硬化の既存呼出しは25℃を既定値とする。
- 温度は流入温度から炉温へ指数緩和し、流入膜が炉より熱い場合も冷却として評価する。
- 入力残留溶剤率は湿量基準の質量割合 `w` とする。乾燥と同じ固形分密度1250 kg/m³、
  溶剤密度790 kg/m³、体積加成性から流入膜厚を固形分質量と溶剤質量へ復元する。
- 固形分質量を保存し、溶剤質量だけを既存の脱離速度で減衰させる。
  出力濃度は `100 * m_solvent / (m_solid + m_solvent)`。
- 最終膜厚は、硬化・圧縮で密度が変化した固形分体積と、残存溶剤体積の和とする。
  溶剤が脱離しても膜厚が変わらない旧挙動を解消する。密度変化係数は従来の合成仮定。

硬化およびラインのmanifestは2.0.0。流入温度の入力次元と応答が変わるため、
旧学習済みbundle、残差校正、保存済み結果をv2の検証として再利用しない。
新しいmanifestで工程模型を再学習・再出力し、連結校正もやり直す必要がある。
既存results/は履歴として残し、今回の結果で上書きしない。

## 固定炉長の連続ライン

`evaluate_line` は従来の独立した工程スケジュールを保持する。
連続ラインは `evaluate_continuous_line` を使い、共通搬送速度から
`residence_time_min = drying_length_m / line_speed_m_min` と
`hold_time_min = curing_length_m / line_speed_m_min` を求める。
時間の重複指定、非正・非有限の炉長、物理モデル範囲外の導出時間は拒否する。
炉長と幅は設備条件として固定スカラーを要求する。

```bash
python -m validation.multistage.run evaluate-line \
  --drying-length-m 234 --curing-length-m 1080 --web-width-m 1 \
  --set coating_gap_um=210 line_speed_m_min=18 web_tension_n=100 \
  air_temperature_c=90 air_speed_m_s=5.5 oven_temperature_c=140 nip_pressure_mpa=0.325
```

炉長は従来の基準速度18 m/min・乾燥13分・硬化60分に合わせたAPI検証用の例で、
設備設計の推奨値ではない。処理量は速度×幅×60で求める。
従来の9変数グリッド監査・最適化・GUIは独立スケジュールのまま。
固定炉長の制約を最適化候補生成にも組み込む作業は今後の対象。

## 次段階の改善候補

今回、以下の物理式・係数は変更していない。

- 乾燥と硬化の熱・物質移動の連成（蒸発潜熱、反応発熱、ガラス化、スキンによる拡散低下）。
  現行エネルギー出力は既存の設備消費量近似であり、閉じた熱収支ではない。
- 塗工方式の確定と供給流量。現在のギャップ依存モデルを維持する。
- 各欠陥を分離した回復・蓄積モデル、材料・設備別の実測校正。
- 切削力とびびり、打抜きの摩耗・板厚依存、めっきのパルス周波数・副反応。
- 電気接続の接触力学、成形履歴、溶接軌跡・熱履歴・IMC・電気抵抗。
